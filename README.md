# Python Dictionaries

## Overview
This project demonstrates the use of Python dictionaries to store, access, update, delete, and iterate through structured data.

## Programs Included
1. Creating and accessing a dictionary.
2. Adding, updating, and deleting dictionary items.
3. Iterating through dictionaries using loops.
4. Student Record Management System using functions and dictionaries.

## Concepts Learned
- Dictionary creation and key-value pairs
- Accessing and modifying dictionary values
- Adding and deleting elements
- Using `items()` and `values()`
- Loops, conditions, and functions
- Building a simple record management system

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
Run any Python program using:

```bash
python 01_create_dictionary.py
```

Replace the filename with the program you want to execute.

The `outputs/` folder contains screenshots of the program outputs.
